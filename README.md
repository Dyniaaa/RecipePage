# Happy Avocado

A recipe management web application built with Next.js.

## Features

- **Authentication:** Users can register and log in to their accounts.
- **Recipes:** Users can browse and create recipes.
- **User Profile:** Each user has a personal profile.
- **Favourite Recipes:** Users can save recipes to their favourites.
- **Responsive Design:** The application is adapted to different screen sizes.

## Technologies

- Next.js
- React
- TypeScript
- Prisma
- NextAuth
- SCSS
